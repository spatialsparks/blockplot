# tools/sketch/example

The pad's own example: one plot, the made-up one, as a plot's file (ST-030) — the plot that the
pad opens on where there is no other, and the first file of its format. Three files: this note,
`plot.json`, and `own.check.js`, which holds that the pad's folder has no plot but this one.
**It never** holds anything of the owner's plot, and `plot.json` is never formatted: one command writes it.

**Its long note is `docs/sketch/example.md`** — "Public API", "Invariants", "Test",
"Gotchas": read the part your card names. What a task changes here is written there, in the
same change. The rules for whoever works on the pad are `../CLAUDE.md`'s.
